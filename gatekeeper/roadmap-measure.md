# ロードマップの測り直し（クローズ手順の補足）

CLAUDE.md「セッションのクローズ手順」を実際に回すための補足。対象は `deliverables/CEFRカタログ_書物ロードマップ.md`（md）と、その Artifact 版。どちらも推計で、正準ではない。

## 計測

```bash
python3 tools/roadmap_measure.py --prev <前回の根拠コミット> --detail
```

- 前回の根拠コミットは、ロードマップ冒頭の「根拠コミット `xxxxxxx`」。出力の「前回」の値が、ロードマップの前回の公表値（字数・一本式・R²・全巻ページ・幅）と一字違わず一致することを**先に**確かめる。一致しなければ測り方がずれているので、数字を文書に写さない
- 数え方の取り決めはスクリプト冒頭の docstring が正。変えると履歴表の過去の値が再現しなくなる
- `--detail` は章ごとの残差と、第3部の章の層（段・例欄・議論・残り）と、帳簿の名指し（シートの散文の他行番号）を出す。帳簿の名指しには偽陽性（「空欄13」など）が混じるので一覧を目で見る
- 層の数え方は前回の公表値と数字単位でずれることがある（`### ` の切り方の違い）。比較は同じスクリプトの値どうしで書く

## 文書の書き換え

書き換える箇所（CLAUDE.md の手順4）：冒頭の基準日・根拠コミット・周の説明、「一行で言うと」、パタン・ランゲージとの比較表、推計の動きの内訳、「いまどこにいるか」の表、マイルストーン表、章の顔ぶれ、次に踏む石、見積もりの根拠（式・履歴表の行・内訳）、採点の節、三変数式と幅の表、四六判の換算、方略・複言語の見積もり。

- 前回の記述は消さず「以下、次の段落はカタログNクローズ時の記述で、数字は当時のまま残している。」で残す
- 予測の採点：前回の「次に踏む石」にある予測（一本式・三変数式の幅・実測型・残差込み）と、実測を並べる。外れの原因は、節・外部No・段の厚みのどれかに帰属させる
- 柱が完結したら、マイルストーン表のその行は「いま」の行に合流させる（行を外して、段落で合流を書く）
- 文章に埋める比較と帰属は、スクリプトの出力で裏を取ってから書く（「〜に次ぐ」「〜より厚い」の取り違えを何度か直前で拾っている）

## 省く場合

CLAUDE.md の手順5のとおり。時間の都合だけで閉じるとき、書物層も帳簿も触らなかった周は測らない。書物層・帳簿を触らずに式が同値なら、基準日と根拠コミットだけ更新して履歴表に行を足さない。
